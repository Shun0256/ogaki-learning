大垣市地域学習Web教材

岐阜県大垣市を題材とした、中高生向けの地域学習Web教材です。

地図上のスポットを探索し、解説やミニクイズを通して大垣市の歴史・文化・水辺について学習できます。

・主な機能
  地図上から学習スポットを選択
  各地点の解説を表示
  3択ミニクイズ
  理解チェック
  実績機能
  全地点学習後の最終確認問題

・学習スポット
  大垣城
  四季の広場
  奥の細道むすびの地記念館
  水門川
  スイトピアセンター
  船町港跡
  加賀野八幡神社
・使用技術
  Vue 3
  Vite
  JavaScript
  Leaflet
  Bootstrap

GitHub Pagesを利用して公開しています。
